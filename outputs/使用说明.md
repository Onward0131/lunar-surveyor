# 月面漫游·17款航天模型库

16套NASA官方模型与原创L-03概念车，可在三维月面环境中自由旋转、缩放和浏览。

## 模型目录

- 探测车与机器人：毅力号、好奇号、机遇号／勇气号、SEV载人探索车、RASSOR采掘机器人、L-03概念车。
- 着陆器：阿波罗登月舱、洞察号、维京号。
- 飞行器与火箭：机智号直升机、航天飞机、土星五号。
- 太空观测与探索：韦布、哈勃、旅行者、卡西尼－惠更斯号、国际空间站。

## 操作

- 左上角按分类选择模型，或用“上一款／下一款”逐个浏览。切换后自动聚焦，保留速度与暂停状态。
- 左键拖动：旋转视角。
- 滚轮：缩放。
- 右键拖动：平移并解除跟随。
- “聚焦模型”或R：返回当前模型并恢复跟随。
- “暂停动画”或空格：暂停／继续。
- “自由飞行”或F：切换自由飞行。
- 自由飞行模式：WASD移动，Q/E升降，Shift加速。
- 触摸设备：单指旋转、双指缩放和平移。

## 本地使用

分享包中的“打开月面漫游.html”已内嵌全部16套NASA模型、运行代码、纹理和解码器，解压后可以双击离线体验，无需联网或安装Node.js。转发时保留来源与许可文件。

如果需要预览分享包里的工程源码，安装Node.js后，在解压后的“工程源码”文件夹使用PowerShell 7执行：

```powershell
npm start
```

浏览器访问终端显示的地址。预览服务器使用Node.js内置功能，无需安装其他依赖；页面所需JavaScript、模型和贴图均在本地。

修改并重新生成离线HTML：依次执行`npm ci`、`npm run build`、`npm run offline`。首次安装依赖需要联网，生成文件位于“工程源码/outputs/打开月面漫游.html”。

## 场景说明

月面是统一展示环境。模型包含不同任务与概念设计，航天器按展示比例缩放，动作属于艺术性演示；不能当作真实任务或完整动力学仿真。探测车巡航、着陆器驻留、太空模型悬浮，机智号双旋翼与RASSOR双滚筒具有独立动画。

NASA原始网格、UV和贴图均保留；部分官方模型使用材质颜色，本身不含位图纹理。来源、处理说明和逐模型统计见NASA模型说明.txt。地表使用Poly Haven的CC0扫描材质；Three.js采用MIT许可，Draco采用Apache License 2.0。

模型目录：`source/vehicle-catalog.mjs`；场景：`source/scene.mjs`；加载与资源管理：`source/nasa-vehicles.mjs`；零件动画：`source/vehicle-rig.mjs`。打包后的运行文件：`app.js`。
